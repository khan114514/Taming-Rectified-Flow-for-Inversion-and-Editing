# 训练证据说明（rfsteps）

**本任务为非训练型任务**：优化面是推理期时间步分配（timestep schedule）设计，
Baseline 与 Reference 均不涉及任何训练、微调或 checkpoint 产出。

- 无 `model/` 目录与 `artifact.json` / `reload.log`：按规范标记 `NOT_APPLICABLE`。
- 评估确定性：同一 method 重复完整评测逐值一致
  （`expert_evidence/anchors.json` 的 `determinism_check`：mushift 两次 full 跑分
  19.528882409499996 == 19.528882409499996；双轨 Agent 复跑亦一致，
  codex round61==round84、seed R17==R22==R26==R47）。
- 因此正式 seed 集为单确定性协议 `seed_deterministic`，B/R 各一次完整运行即构成
  全部正式成对证据；无 seed 挑选空间（不存在多次运行可供筛选）。
- Baseline 与 Reference 使用完全相同的协议：NFE=100/图、同 16 图、同 scorer
  （v2 sha256 `17e17794…`，测量路径与 v3 一致）、同 full split。
- v3 变更（2026-10-03）：新增独立上限锚点 `upper_bound`（U=21.5356，codex round61
  实测最强 schedule），score 改为未裁剪 (PSNR−B)/(U−B)；仅影响归一化计算，
  不影响既有 PSNR 测量值。
