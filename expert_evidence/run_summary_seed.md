# RF-Steps 研究总结：反向幂律时间步分配

## 最终成绩

- **最佳 PSNR：21.662 dB**（rev_power p=1.2）
- **Score：1.0**（超过 Reference 锚点）
- **Baseline 提升：+2.30 dB**（相对于官方 time_shift baseline 的 19.36 dB）
- **Reference 提升：+1.44 dB**（相对于 sine reference 的 20.22 dB）
- **验证次数：4 次独立运行完全一致**（R17、R22、R26、R47，确定性可靠）

## 最佳方法

**反向幂律 (Reverse Power Law) schedule**：

```
t(i) = 1 - (i / N)^p,  p = 1.2
```

- 步长从 t≈1（高噪声端）到 t≈0（低噪声端）单调递增
- 增长率递减（减速增长 / decelerating growth）
- 步长比约 2.28x（首步 ≈ 0.021，末步 ≈ 0.048）

实现在 `best_method.py` 中。

**四次独立验证一致**（round17、round22、round26、round47 均精确等于 21.662dB），方法确定性可靠。

- 指数修正（±方向）：均降低性能，最优在 c=0

## 理论解释

RF-Solver 使用二阶 Taylor 展开，每步截断误差 O(h³·f''')。
最优步长分配满足误差等分布原则：h² · |f'''| = 常数 → h ∝ |f'''|^(-1/2)
（注：经验上 1/2 幂比 1/3 幂更优，可能因 RF-Solver 有效阶数低于标称二阶）。

实验表明最优步长分布为减速增长，形状接近：
```
h(t) ∝ (1-t)^((p-1)/p),  p = 1.2
```

即三阶导数（误差密度）在 t→1 时按 (1-t)^(-2(p-1)/p) ≈ (1-t)^(-1/3) 发散，
属于温和的立方根型发散。反向幂律 p=1.2 恰好匹配此误差分布。

**p=1.2 处于数值稳定性边界**：
- p > 1.2：步长更不均匀，部分图像出现共振式不稳定（景观粗糙，存在多峰多谷）
- p < 1.2：更接近均匀，但部分图像反演质量骤降
- p = 1.2：保持所有图像稳定的最不均匀分布，也是精度最高点
